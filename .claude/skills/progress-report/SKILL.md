# 进展汇报 `v1.1`

你想了解任务进展时，**一律**按本规范汇报。模板：`templates/progress-report.md`。

## 1. 确定范围
- 没指定范围 → 全部 active 项目 + 未完成的计划任务（paused、已结束的不列，结论里提一句数量）
- 指定项目、计划或领域 → 只汇报那一块，可以细化到任务级
- 有歧义就按最可能的理解先汇报，在结论里说明范围

## 2. 取数（先客观，再补充）
```bash
python tools/plan.py --report                 # 项目 + 计划任务的原始数据表
python tools/plan.py --report --proj <slug>   # 单个项目
python tools/plan.py --report --plan <计划>    # 单个计划
```
再用以下来源补充或纠正：
- 最近的夜间巡检报告 `reviews/nightly/`（最近几天的提交和 diff 摘要）
- 项目档案的「当前状态」「时间线」，计划的「进展日志」
- 近几天的 journal；必要时 `python tools/collect.py --days N` 看最新提交

原始表里「当前进展」只是档案首行，**要改写成一句话的实际进展**，不要照抄「近 30 天客观数据」这类统计句。

## 3. 字段口径
| 字段 | 口径 |
|---|---|
| 项目 | 项目 slug（和任务行的 `proj:` 一致）；领域写「life（领域）」这类；`plan.py --report` 推不出来的「?」查清补上 |
| 事项 | 项目这一行写「项目整体」；任务写「计划名#任务号 任务」 |
| 当前进展 | 一句话：最近完成了什么 / 正在做什么。有依据就带上（PR 号、提交、日期） |
| 开始日期 | 项目：档案 frontmatter 的 `started`（仓库创建日等客观依据）；任务：任务行的 `start:`。没有就写 `—` |
| 记录日期 | 这条进展最后一次被记录的日期：档案「当前状态」的更新日期、任务的 `upd:`、巡检报告日期，取最新的一个 |
| 当前状态 | 固定词表：🟢 进行中 · 🟡 受阻 / 有风险 · ⚪ 未开始 · ⏸ 暂停 · ✅ 已完成 · 🔍 观望 |

记录日期距今超过 7 天的，在状态后加「（信息过期）」，并在说明里点出来。

## 4. 呈现：金字塔结构
**顶部 · 结论**（2–4 句）：整体情况一句话；最值得关注的 1–2 件事（进展最大的、风险最大的）；范围说明。

**中间 · 进展表**：
| 项目 | 事项 | 当前进展 | 开始日期 | 记录日期 | 当前状态 |
|---|---|---|---|---|---|

- 排序：受阻 / 有风险 → 进行中（按记录日期从新到旧）→ 未开始 → 暂停 / 观望
- 表格下面写 **说明**：数据来源和截止时间、哪些是推断、信息过期的条目、口径上的特殊情况

**底部 · 下一步建议**：按优先级 1–5 条。每条写清做什么、为什么、谁来做（我 / 你 / agent）；推断标（推断）。需要你拍板的单独列出来：对话里按 [report-cards](../report-cards/SKILL.md) 出卡片，放在结论后、进展表前（卡片在前、表格在后，最多 5 张）；存文件的报告（夜间巡检、`reviews/progress/`）照旧列在「需要你拍板」，每条带编号和一句推荐。

## 5. 收尾
- 你只是问一下 → 在对话里回复即可，不落文件
- 你说「存一下」，或者这是周回顾 / 夜间巡检的报告 → 存到 `reviews/progress/YYYY-MM-DD-<范围>.md`（夜间巡检存 `reviews/nightly/YYYY-MM-DD.md`）
- 汇报中发现档案过期或数据不一致 → 顺手修正，并在回复末尾的「已记」里写明

## 6. 和汇报卡片的进展表
[report-cards](../report-cards/SKILL.md) 卡片后面那张进展表是本 skill 进展表的**简版**，列对得上，口径不变：

| 卡片进展表 | 本 skill 的列 | 说明 |
|---|---|---|
| 项目 | 项目 | 同一口径（slug；领域写「life（领域）」） |
| 问题 | 事项 | 同一件事；卡片表里有卡点时把卡点写进去（「T3 规范单开 PR：等你定 base」） |
| 状态 | 当前状态 | 词表见下 |
| 进展 | 当前进展 | 同一口径：一句话带依据 |
| 下一步（需要时） | — | 本 skill 把下一步放在底部「下一步建议」 |
| — | 开始日期、记录日期 | 简版不列；记录日期超过 7 天的，在进展里注「（信息过期）」 |

- **什么时候用哪张**：你问「进展怎么样」、夜间巡检、周回顾 → 本 skill 的六列完整表；你要回复的事（待处理、要拍板、待验收、待查看）→ report-cards 的卡片 + 简版表。一次回复里两样都有时，卡片在结论后，表格用六列完整表，不再另出简版
- **状态词表的对应**：两边共用 🟢 进行中、⏸ 暂停、✅ 已完成；本 skill 的「🟡 受阻 / 有风险」对应卡片表的「🟡 等你 / 受阻」（风险已经变成问题的写「🔴 出问题」）；「⚪ 未开始」对应「⚪ 排队」；「🔍 观望」只在本 skill 用
- **可配置**：状态词表可以和卡片表统一，也可以保持这里的口径；两套并存时在周日盘点问一次要不要统一
