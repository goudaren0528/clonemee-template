# 周日事情盘点 `v1`

每周日由你主动发起（周日没有定时运行）。核心：**把所有积累的事拿出来过一遍，一件不漏**；逐件确认做不做、目标、时间、顺序。
方法来自 **GTD（Getting Things Done）的每周回顾（Weekly Review）**：Get Clear 清空 → Get Current 逐项过、排下周 → Get Creative 回看目标。

## 0. 准备（开场前，几分钟）
```bash
python tools/collect.py --since <本周一> --write   # 本周的客观数据（周回顾用）
python tools/inventory.py --write                  # 生成 reviews/inventory/YYYY-Www.md：全部未结事项，带决定列
python tools/recall.py --due                       # 要巩固或复核的记忆
```
- 盘点表是这次仪式的底稿。工具已经去重，同一件事出现在多处的标了「另见 N 处」；你再快速扫一遍，把明显已经完成的标出来，问的时候一并确认
- 本周的 `reviews/nightly/` 和 `plans/daily/` 也扫一眼：没完成的日事项、巡检里待拍板的，确认都已经在表里

## 1. 开场（先给结论）
- 本周回顾三句话：推进了什么、卡在哪、下周最重要的是什么（推断）
- 盘点规模：共 N 件，按组的数量；预计要过多久
- 流程：先清空脑子 → 逐组过 → 排下周

## 2. 清空脑子（GTD 的 Get Clear）
问一句：「这周还有什么没记下来的？工作、生活、答应别人的、别人答应你的、想做的都算。」把回答逐条加进盘点表的「收集」一节（N1、N2……）。可以多问一轮。

## 3. 逐组过（一件不漏）
按「计划任务 → 项目 → 零散待办 → 记忆里的未结和承诺 → 巡检待拍板 → journal 待办 → 会议行动项 → 领域 → 以后再说」的顺序，每批 8–12 件，用表格发出来：

| # | 项目 | 事项 | 来源 | 我的建议（推断） |
|---|---|---|---|---|

项目列照抄盘点表（工具推的），「?」的过之前查清补上。你可以批量回复，比如「I3 做，周二；I5 不做；I7 以后」。每件落到一个**决定**：
| 决定 | 含义 | 还要问 |
|---|---|---|
| 做 | 自己做 | 目标 / 完成标准、什么时候 |
| 委托 | 交给别人或 agent | 交给谁、什么时候跟进 |
| 等别人 | 球在别人那里 | 等谁、什么时候追 |
| 以后再说 | 现在不做，也不丢 | 什么情况下再拿出来 |
| 不做 | 放弃 | 一句理由 |
| 已完成 | 其实已经做完了 | — |

- 没有明确目标的「做」，帮你把完成标准说清楚；需要拆解的，标记会后按 `plan` skill 建计划
- 每批过完就把决定写回盘点表，防止中断丢失
- 你说「今天先到这」时，记下停在哪一组，下次从那里继续

## 4. 排下周（Get Current）
- 「做」的事按重要性和依赖排出执行顺序，挑 3–5 个作为下周焦点
- 按 [templates/weekly-plan.md](../../../templates/weekly-plan.md) 写 `plans/weekly/YYYY-Www.md`（下周）：焦点、全部「做」的事按顺序列出（带日期）、「等别人」清单、本周要追的委托
- 对照 `plans/goals.md`：哪个长期目标这周没有任何事项在推进，点出来（推断）

## 5. 落地（逐个来源改到位）
| 决定 | 怎么改 |
|---|---|
| 已完成 | 在来源处打勾（`[x]`），计划任务改状态并写进展日志 |
| 不做 | 来源处改为 `[-]`，或者删掉并在 journal 记一句理由 |
| 以后再说 | 移到 `plans/someday.md`（「- [ ] 事项 · 来源 · 日期 · 再看的条件」），原处删除或指向它 |
| 做 / 委托 / 等别人 | 写进周计划；需要拆解的按 `plan` skill 建计划或更新计划；零散的留在 todo.md 并补上日期 |
| 记忆里的未结和承诺 | 已解决的在会话记忆里打勾；thread 卡解决了就改为 `status: archived` |
| 目标有变化 | 更新 `plans/goals.md` 和项目档案的「当前状态」 |

跑一次 `python tools/build_index.py --check`，把模板覆盖和 frontmatter 的问题一并处理。然后：盘点表 frontmatter 改为 `status: done`，加上 `completed: <今天>`（**会话启动的 GTD 超期检查靠它判断**）；按 `playbooks/memory.md` §5 做记忆巩固；journal 记一条 `#weekly`；更新会话记忆；`python tools/build_index.py`；提交。

## 6. 收尾回复
结论一句（过了多少件、各种决定各多少）→ 下周焦点表（顺序、项目、事项、目标、时间）→ 需要跟进的人和事。最后跑一次 `python tools/inventory.py --brief`，确认剩下的都有了归宿。
